# Vynexa News Bot

ربات انتشار خودکار خبر فارسی برای تلگرام.

## فایل‌های لازم
- `bot.py` فایل اصلی ربات
- `requirements.txt` وابستگی‌ها
- `Procfile` دستور اجرای ربات در هاست

## تنظیم متغیرهای محیطی در هاست
- `BOT_TOKEN` = توکن ربات تلگرام
- `ADMIN_ID` = آیدی عددی مدیر
- `NEWS_CHANNEL` = آیدی کانال مقصد، مثل `@YourChannel`
- `PORT` = `8080` (در صورت نیاز هاست)
- `OPENAI_API_KEY` = اختیاری؛ فقط اگر ترجمه با هوش مصنوعی می‌خواهی
- `OPENAI_MODEL` = اختیاری؛ پیش‌فرض `gpt-4o-mini`

ترجمه به یک سرویس وابسته نیست. ربات ابتدا سرویس‌های مستقل LibreTranslate و Lingva را امتحان می‌کند، سپس MyMemory و در آخر Google Translate را؛ اگر کلید OpenAI تنظیم شده باشد، آن را هم در ابتدای زنجیره امتحان می‌کند. ترجمه‌های موفق در دیتابیس ذخیره می‌شوند تا دوباره درخواست نشوند. اگر ترجمه عنوان انگلیسی در دسترس نباشد، آن خبر با عنوان انگلیسی منتشر نمی‌شود و برای دور بعد نگه داشته می‌شود؛ بنابراین عنوان نصفه یا انگلیسی وارد کانال نمی‌شود. سرویس‌های عمومی ممکن است گاهی محدود یا موقتاً قطع باشند.

## اجرای ربات
Start Command هاست باید دقیقاً این باشد:

```bash
python bot.py
```

اگر فایل‌های قدیمی بازی در مخزن مانده‌اند، آن‌ها را از مخزن حذف کن یا مطمئن شو هاست فقط `bot.py` را اجرا می‌کند. فایل قدیمی `secret_society_bot.py` نباید اجرا شود.

ربات را در کانال ادمین کن و اجازه ارسال پست بده. سپس در ربات `/panel` را بزن و کانال را تنظیم کن.

فاصله پیش‌فرض بررسی خبرها ۶۰ ثانیه است. ترجمه‌ها در SQLite ذخیره می‌شوند تا خبرهای تکراری دوباره ترجمه نشوند. اگر ترجمه خلاصه در دسترس نباشد، فقط عنوان فارسی منتشر می‌شود؛ اگر خود عنوان ترجمه نشود، خبر فعلاً منتشر نمی‌شود و چرخه خبرها ادامه پیدا می‌کند.

منبع پوشش زنده فارسی ایران‌اینترنشنال نیز به‌صورت مستقل بررسی می‌شود؛ هر به‌روزرسانی با شناسه جداگانه ثبت می‌شود تا خبرهای قبلی دوباره منتشر نشوند.

پایگاه داده پیش‌فرض `secret_society.sqlite3` است؛ برای حفظ تنظیمات و آمار، فایل دیتابیس را حذف نکن.


## اولویت و قالب انتشار
- اولویت اول: اعتراضات و اعتصاب‌های ایران از همه منابع فعال.
- بعد از آن: خبرهای مهم سیاسی، امنیتی، دیپلماتیک و اقتصادی ایران.
- سپس: خبرهای مهم جهان؛ خبرهای سبک و حاشیه‌ای/سرگرمی/خوراکی فیلتر می‌شوند.
- نام منبع ایران‌اینترنشنال فقط «Iran International» نمایش داده می‌شود.
- زیر هر خبر، ربات شناسه کانال مقصد را از تلگرام می‌خواند و با نشان 🛑 درج می‌کند.
- رسانه از RSS و در صورت نبودن، از تصویر/ویدئوی معرفی‌شده در صفحه اصلی خبر استخراج و برای تلگرام بارگذاری می‌شود. اگر ناشر هیچ رسانه‌ای ارائه نکند یا دسترسی آن مسدود باشد، ربات فقط لینک پیش‌نمایش‌دار را به‌عنوان راه‌حل جایگزین می‌فرستد.
